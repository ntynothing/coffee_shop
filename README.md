# Кофейня

Учебный проект: веб-приложение кофейни на HTML, CSS и JavaScript.

## Возможности

Пользователь: каталог с поиском и фильтром, корзина, оформление заказа с чеком, регистрация и вход, блог.

Администратор: управление товарами и блогом, просмотр заказов, доска стикеров с drag-and-drop, статистика с графиком и таблицей.

## Запуск

Откройте `index.html` в браузере или запустите через Live Server в VS Code.

Администратор: `admin@coffee.ru` / `admin123`

## Структура

- `index.html`, `catalog.html`, `cart.html`, `blog.html`, `login.html`, `admin.html`, `stats.html` — страницы
- `style.css` — оформление
- `app.js` — логика, данные хранятся в localStorage
